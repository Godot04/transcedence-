Privacy Policy

This Privacy Policy explains how Battleship Transcendence collects, stores and uses information provided by users of the application.

1. Information We Collect

When you create an account, we may collect:

  • Login / username
  • Email address
  • Password information stored as a secure password hash
  • Profile picture, if you choose to upload one
  • Matchmaking rating and game-related statistics
  • Achievements and account progression

2. Authentication Information

Passwords are not stored as plain text. The application stores password hashes generated using a salted password hashing mechanism.

If you use 42 OAuth authentication, information provided by 42 may be used to create or connect your Battleship Transcendence account.

3. Profile Pictures

Users may upload a profile picture voluntarily. Uploaded profile pictures are stored by the application and associated with the corresponding user account.

Users should only upload images that they have the right to use and that comply with applicable laws and the rules of the application.

4. How We Use Information

Information is used to provide and operate the service, including:

  • Creating and managing user accounts
  • Authenticating users
  • Displaying user profiles
  • Managing matchmaking ratings
  • Tracking achievements and progression
  • Providing multiplayer game functionality

5. Data Storage

Account information is stored in the application's database. Uploaded files are stored using the application's server-side storage system.

6. Data Sharing

We do not intentionally sell or rent personal account information to third parties.

Information may be transmitted to external authentication providers when a user explicitly chooses an external authentication method such as 42 OAuth.

7. Data Security

Reasonable technical measures are used to protect account information against unauthorized access. However, no Internet service can guarantee absolute security.

8. User Rights

Users may request information concerning their account data and may request correction or deletion of their account where supported by the application.

9. Changes to This Policy

This Privacy Policy may be updated when the application or its data-processing practices change. Updated versions will be published on this page.

10. Contact

For privacy-related questions, users should contact the project maintainers through the contact information provided with the project.
